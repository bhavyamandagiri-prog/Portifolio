# Portfolio - Bhavya Mandagiri

A modern, premium, and highly professional academic portfolio website showcasing my engineering achievements, technical skills, and projects at the intersection of **VLSI**, **Full Webstack Development**, and **AI**.

## 🚀 Tech Stack
- **Frontend:** HTML5, CSS3 (Vanilla Glassmorphism UI tokens)
- **Interactions & Logic:** ES6 JavaScript (Modular)
- **Components:** Interactive CGPA Gauge, Real-Time GPA Simulator, Dynamic Certificate Gallery Canvas, CV Quick-Access Hub, AI-Powered Floating Chatbot Assistant

## 📁 Project Structure
- `index.html` - Semantic HTML framework, core tags, metadata, and page layouts.
- `styles/` - Custom design system tokens, layout grids, components, and animations.
- `js/` - Modular ES6 application engines (typewriter, dashboard, gallery canvas, chatbot, resume version logs).
- `images/` - High-fidelity project screenshots, graphics, and profile photos.

## ⚙️ How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/bhavyamandagiri-prog/Portifolio.git
   ```
2. Navigate to the project folder and launch a local development server:
   - **Using Python:**
     ```bash
     python -m http.server 8000
     ```
   - **Using Node.js (http-server):**
     ```bash
     npx http-server
     ```
3. Open `http://localhost:8000` in your web browser.
